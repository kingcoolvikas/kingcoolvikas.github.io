// Selected Findings

Bugs I've Written Up

Three representative findings from bug-bounty work — what broke, how I found it, and what an attacker could have done with it. Full technical writeups are on Medium.

IDOR · INJECTION JUN 2025

Mass SMS injection + IDOR in identity verification

IMPACTAny account could deliver an attacker-controlled link to any phone number, and predictable short-link IDs exposed other users' ID-upload flows.

  • POST /api/v1/verification/send-sms accepted an arbitrary url and to_phone_number, returned 200, and delivered the link.
  • Upload links used a sequential short-code pattern, so live links to other accounts could be enumerated.
  • Chained: mass phishing delivery at scale plus hijacking of identity verification for any user.
Read the full writeup
RECON · INFO DISCLOSURE JUN 2025

Private group chats exposed via VirusTotal recon

IMPACTLive group-chat URLs gave unauthenticated access to full message history and shared files for multiple organisations.

  • The "Available by link" feature granted anonymous access to any group URL containing a valid token.
  • Queried VirusTotal's undetected_urls for the domain instead of crawling the app itself.
  • Confirmed read access to conversations and files across several organisations; bounty awarded.
Read the full writeup
XSS · WEB DEC 2022

Filter bypass to XSS on a crypto exchange

IMPACTScript execution in a translation feature, bypassing the input sanitiser the site relied on. $200 bounty paid.

  • The translation input sanitised simple payloads but not a full polyglot.
  • Fuzzed the parameter with Burp Intruder and used response-length analysis to surface surviving payloads.
  • A <details open ontoggle> polyglot executed where plain tags were neutralised.
